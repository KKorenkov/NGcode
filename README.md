# VoxPhone

Минималистичный Android-софтфон на [Voximplant Android SDK](https://voximplant.com/docs/getting-started/platform/android) 3.3.0.
Звонит на обычные телефоны с купленного у Voximplant номера и принимает звонки на этот номер.

Что умеет:

- вход пользователем Voximplant (`user@app.account.voximplant.com`), автоматический вход и переподключение;
- исходящий звонок на любой номер;
- входящий звонок: рингтон, уведомление на весь экран (в том числе на экране блокировки), «Ответить» / «Отклонить»;
- во время разговора: таймер, выключение микрофона, громкая связь, тоновый набор (DTMF) для голосовых меню;
- foreground-сервис, чтобы разговор не обрывался в фоне и при выключенном экране.

Код: `app/src/main/java/com/ngcode/voxphone/`

| Файл | Что внутри |
|---|---|
| `VoxApp.kt` | инициализация SDK (`VICore`, `VICalls`) |
| `Phone.kt` | подключение, вход, звонки, рингтон и гудки — вся логика |
| `MainActivity.kt` | один экран: вход / набор номера / звонок |
| `CallService.kt` | foreground-сервис на время звонка |
| `CallNotifications.kt`, `CallActionReceiver.kt` | уведомления и кнопки в них |
| `voxengine/*.js` | сценарии для облака Voximplant |

## 1. Настройка в панели Voximplant

1. **Приложение.** В [панели управления](https://manage.voximplant.com) → *Applications* создайте приложение, например `phone`.
2. **Пользователь.** В приложении → *Users* создайте пользователя, например `user1` с паролем.
   Полный логин для входа будет таким: `user1@phone.ВАШ_АККАУНТ.voximplant.com`.
3. **Номер.** Купленный номер прикрепите к приложению (*Numbers* → *Attach*).
4. **Сценарии.** В приложении → *Scenarios* создайте два сценария и вставьте в них код:
   - `inbound` — из файла [`voxengine/inbound.js`](voxengine/inbound.js), впишите в `USERNAME` имя пользователя (`user1`);
   - `outbound` — из файла [`voxengine/outbound.js`](voxengine/outbound.js), впишите в `CALLER_ID` свой купленный номер.
5. **Правила маршрутизации** (*Routing*), порядок важен:
   1. `inbound`: шаблон — ваш номер (например `74951234567`), сценарий `inbound`.
      Если панель предлагает привязать номер к правилу, привяжите купленный номер к этому правилу.
   2. `outbound`: шаблон `.*`, сценарий `outbound`. Это правило должно стоять **ниже** `inbound`.
6. **Нода.** Запомните ноду аккаунта (`Node1`…`Node13`), она видна в панели (в настройках аккаунта / при создании пользователя).
   Её нужно выбрать на экране входа в приложении.

Как идёт звонок:

```
Исходящий:  Приложение ──createCall(номер)──▶ правило outbound ──callPSTN(номер, CALLER_ID)──▶ телефон
Входящий:   Телефон ──▶ купленный номер ──▶ правило inbound ──callUser(user1)──▶ приложение
```

## 2. Сборка и запуск

Нужны Android Studio (или Android SDK с платформой 36) и JDK 17+.

1. Откройте папку проекта в Android Studio, дождитесь синхронизации Gradle.
2. Подключите телефон (Android 9+) и нажмите *Run*.
   Из консоли: `./gradlew assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`.
3. В приложении введите полный логин, пароль, выберите ноду и нажмите «Войти».
4. Разрешите доступ к микрофону и уведомлениям.

На Android 14+ для показа входящего звонка поверх экрана блокировки может понадобиться
разрешение «Полноэкранные уведомления» (Настройки → Приложения → VoxPhone).

## Ограничения (осознанно, ради минимализма)

- **Входящие приходят, пока процесс приложения жив и подключён.** Если система выгрузила приложение
  (долго в фоне, режим энергосбережения), входящий не дойдёт. Для надёжного приёма нужны push-уведомления:
  Firebase (`google-services.json`), `Client.registerForPushNotifications(PushConfig(token, packageName), …)`
  после входа и `Client.handlePushNotification(remoteMessage.data)` в `FirebaseMessagingService`,
  плюс push-сертификат в панели Voximplant. Также помогает отключить оптимизацию батареи для приложения.
- Пароль хранится в приватных настройках приложения (`SharedPreferences`), чтобы входить автоматически.
  Для продакшена лучше перейти на вход по токену (`Client.loginWithAccessToken` / `refreshToken`).
- Один звонок одновременно: второй входящий во время разговора отклоняется как «занято».
- Только аудио, без видео.
